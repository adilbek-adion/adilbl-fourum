# Как включить приём заявок: письмо на Gmail + запись в Google Таблицу

Занимает 10 минут, делается один раз. Ничего платить не нужно, всё работает внутри вашего Google-аккаунта.

Итог: посетитель нажимает «Отправить заявку» → строка появляется в таблице → вам приходит письмо, на которое можно сразу ответить клиенту.

---

## Шаг 1. Создайте таблицу

1. Зайдите на [sheets.new](https://sheets.new) — откроется новая пустая таблица.
2. Назовите её, например, **«Заявки с сайта adion form»**.

Лист и шапку создавать не нужно — скрипт сделает это сам при первой заявке.

## Шаг 2. Вставьте скрипт

1. В этой же таблице: меню **Расширения → Apps Script**.
2. Удалите весь код, который там есть по умолчанию (`function myFunction() {}`).
3. Откройте файл `apps-script.gs` из папки сайта, скопируйте **всё** его содержимое и вставьте в редактор.
4. Вверху файла при необходимости поменяйте адрес почты:
   ```js
   var NOTIFY_EMAIL = 'adilbek.abdrassk@gmail.com';
   ```
5. Нажмите значок дискеты (**Сохранить проект**).

## Шаг 3. Проверьте, что письмо приходит

1. В редакторе скрипта вверху выберите функцию **`testLead`** и нажмите **Выполнить**.
2. Google попросит разрешения — это нормально, скрипт ваш собственный:
   - **Разрешить доступ** → выберите свой аккаунт
   - экран «Google не проверил это приложение» → **Дополнительные настройки** → **Перейти к проекту (небезопасно)**
   - **Разрешить**
3. Через несколько секунд: в таблице появится тестовая строка, на почту придёт письмо «Заявка с сайта».

Если письмо пришло — половина дела сделана. Тестовую строку из таблицы потом удалите.

## Шаг 4. Опубликуйте скрипт

1. В редакторе нажмите синюю кнопку **Развернуть → Новое развёртывание**.
2. Слева от «Выберите тип» нажмите шестерёнку → **Веб-приложение**.
3. Заполните:
   - **Описание**: `Приём заявок с сайта`
   - **Запуск от имени**: **Я** (ваш адрес)
   - **У кого есть доступ**: **Все** ← это обязательно, иначе форма не сможет отправлять
4. **Развернуть** → скопируйте **URL веб-приложения**. Он выглядит так:
   ```
   https://script.google.com/macros/s/AKfycbx...длинный набор символов.../exec
   ```

> «У кого есть доступ: Все» открывает только приём заявок. Ни таблицу, ни почту посторонние не видят.

## Шаг 5. Вставьте адрес в сайт

Откройте `index.html`, найдите в начале скрипта строку:

```js
var FORM_ENDPOINT = '';
```

и вставьте между кавычками скопированный адрес:

```js
var FORM_ENDPOINT = 'https://script.google.com/macros/s/AKfycbx.../exec';
```

Сохраните файл. Готово — форма работает.

## Шаг 6. Проверьте вживую

Откройте сайт, заполните форму настоящими данными и нажмите «Отправить заявку». Должно произойти три вещи:

1. появится зелёный экран «Заявка отправлена»;
2. в таблице появится новая строка;
3. на Gmail придёт письмо.

# Уведомления в Telegram (по желанию)

Заявка будет падать вам в Telegram сама, через секунду после отправки. Бесплатно. Клиенту при этом ничего делать не нужно.

> Для WhatsApp такое сделать нельзя: Meta пускает автоматические сообщения только через платный WhatsApp Business API. Поэтому WhatsApp остаётся кнопкой, по которой пишет сам клиент.

## Шаг 1. Создайте бота

1. В Telegram найдите **@BotFather** → отправьте `/newbot`
2. Придумайте имя (любое) и логин бота (должен заканчиваться на `bot`, например `adionform_leads_bot`)
3. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

**Токен — это пароль от бота. Не выкладывайте его в код и на GitHub.** Ниже он кладётся в защищённое место.

## Шаг 2. Узнайте свой id

1. Найдите в Telegram **@userinfobot** → отправьте ему любое сообщение
2. Он ответит строкой `Id: 123456789` — это число и есть ваш `TG_CHAT_ID`
3. Откройте **своего** бота (из шага 1) и нажмите **Start** — без этого бот не имеет права вам писать

## Шаг 3. Впишите их в настройки скрипта

1. В редакторе Apps Script слева нажмите шестерёнку — **Настройки проекта**
2. Пролистайте вниз до **Свойства скрипта** → **Добавить свойство**
3. Добавьте два свойства и сохраните:

| Свойство | Значение |
|---|---|
| `TG_TOKEN` | токен от BotFather |
| `TG_CHAT_ID` | число от userinfobot |

Именно так токен не попадает ни в код, ни в репозиторий на GitHub.

## Шаг 4. Проверьте

В редакторе выберите функцию **`testTelegram`** и нажмите **Выполнить** — в Telegram придёт тестовая заявка с кнопками «Написать в WhatsApp», «Позвонить» и «Ответить на почту».

Если сообщение не пришло:
- не нажали **Start** у своего бота;
- перепутаны местами токен и id;
- в свойствах опечатка в названии — должно быть ровно `TG_TOKEN` и `TG_CHAT_ID`.

После настройки переопубликуйте скрипт: **Развернуть → Управление развёртываниями → карандаш → Версия: Новая → Развернуть.**

---

## Что важно знать

**Пока `FORM_ENDPOINT` пустой** — форма работает по-старому, через WhatsApp. Сайт не ломается, просто заявки не пишутся в таблицу.

**Если интернет у клиента подведёт** — сайт повторит отправку, а если и это не сработает, откроет WhatsApp с уже готовым текстом заявки. Заявка не потеряется.

**Защита от спама.** В форме есть невидимое поле-ловушка: боты его заполняют, люди — нет. Такие заявки скрипт молча отбрасывает.

**Ответ клиенту.** В письме нажмите «Ответить» — письмо уйдёт на почту клиента, а не вам самому.

**Уведомления на телефон.** Поставьте приложение Gmail и включите уведомления — заявки будут приходить моментально. Если хотите, можно добавить и дублирование в Telegram, скажите.

**Лимиты Google:** 100 писем в сутки для обычного аккаунта. Для потока заявок с сайта этого хватает с большим запасом.

## Если что-то пошло не так

| Что видно | В чём дело |
|---|---|
| «Не удалось отправить», открывается WhatsApp | В `FORM_ENDPOINT` неверный адрес, либо при публикации выбран доступ не «Все» |
| Строка в таблице есть, письма нет | Не выданы разрешения на отправку почты — выполните `testLead` (шаг 3) |
| Ничего не происходит | Откройте адрес из `FORM_ENDPOINT` в браузере: должно появиться `{"ok":true,"status":"Приём заявок работает"}` |
| Изменили скрипт, а поведение старое | После правок нужно заново: **Развернуть → Управление развёртываниями → значок карандаша → Версия: Новая → Развернуть** |
